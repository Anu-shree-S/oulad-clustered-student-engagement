# TrackWise Dashboard

Run from this folder:

```bash
pip install -r requirements.txt
streamlit run app.py
```

The redesigned application uses a top control ribbon and horizontal page tabs; there is no sidebar navigation.

See `docs/dashboard-redesign.md` for expected OULAD, recommendation, behavioural and optional prediction artefacts.

Prototype credentials are defined in `config/demo_users.py`.
